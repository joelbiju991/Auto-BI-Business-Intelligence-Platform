📈 Automated Business Intelligence Platform

An end-to-end data pipeline and interactive dashboard that transforms raw financial and retail datasets into actionable insights.

💡 Key Features
Automated ETL Pipeline: Upload raw `.csv` or `.xlsx` files to automatically clean, standardize, and format the data.
Database Integration: Securely loads and stores the cleaned data into a local SQLite database.
Interactive Executive Dashboard: Features dynamic KPIs, a Time Series Revenue chart, and categorical Bar charts.
Advanced Multi-Filtering: Instantly slice the data by Country, Segment, and Product.
Data Export: One-click download of the standardized dataset with UI-friendly column headers.

 🛠️ Tech Stack
Frontend/UI: Python, Streamlit
Data Processing (ETL): Pandas
Database: SQLite, SQLAlchemy
Version Control: Git, GitHub
